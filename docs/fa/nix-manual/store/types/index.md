## قالب URL انبار

انبارها با استفاده از یک نحو شبیه به URL مشخص می‌شوند. برای مثال، دستور

```console
# nix path-info --store https://cache.nixos.org/ --json \
  /nix/store/1542dip9i7k4f24y6hqgd04hmvid9hr5-coreutils-9.1
```

اطلاعات مربوط به یک مسیر انبار را در کش باینری HTTP واقع در https://cache.nixos.org/ که نوعی انبار است، دریافت می‌کند.

URLهای انبار می‌توانند با استفاده از رشته‌های پرس‌وجو (query string) در URL، یعنی با الحاق `?name1=value1&name2=value2&...` به URL، **تنظیمات انبار** را مشخص کنند. برای مثال،

```
--store ssh://machine.example.org?ssh-key=/path/to/my/key
```

به Nix می‌گوید تا از طریق پروتکل SSH و با استفاده از `/path/to/my/key` به عنوان کلید خصوصی SSH، به انبار روی یک ماشین راه دور دسترسی پیدا کند. تنظیمات پشتیبانی‌شده برای هر نوع انبار در ادامه مستند شده است.

### URL خاص `auto` {#auto}

URL انبار خاص `auto` باعث می‌شود که Nix به صورت خودکار یک انبار را به شرح زیر انتخاب کند:

* اگر `/nix/var/nix` توسط کاربر فعلی قابل نوشتن باشد، از [انبار محلی](./local-store.md) یعنی `/nix/store` استفاده کنید.

* در غیر این صورت، اگر `/nix/var/nix/daemon-socket/socket` وجود دارد، [به دیمن Nix که روی آن سوکت در حال گوش دادن است متصل شوید](./local-daemon-store.md).

* در غیر این صورت، فقط روی لینوکس، از [انبار چروت محلی](@docroot@/store/types/local-store.md#chroot) یعنی `~/.local/share/nix/root` استفاده کنید که اگر وجود نداشته باشد، به طور خودکار ایجاد خواهد شد.

* در غیر این صورت، از [انبار محلی](./local-store.md) یعنی `/nix/store` استفاده کنید.
