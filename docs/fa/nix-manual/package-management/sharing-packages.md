# اشتراک‌گذاری بسته‌ها بین ماشین‌ها

گاهی اوقات می‌خواهید بسته‌ای را از یک ماشین به ماشین دیگری کپی کنید. یا می‌خواهید چند بسته را نصب کنید و می‌دانید که ماشین دیگری از قبل برخی یا تمام آن بسته‌ها یا وابستگی‌هایشان را دارد. در این صورت، مکانیسم‌هایی برای کپی کردن سریع بسته‌ها بین ماشین‌ها وجود دارد.
