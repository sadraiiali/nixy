# نام

`nix-store --generate-binary-cache-key` - تولید جفت‌کلید برای استفاده در یک کش باینری

## خلاصه

`nix-store` `--generate-binary-cache-key` *key-name* *secret-key-file* *public-key-file*

## توضیحات

این دستور یک [جفت‌کلید Ed25519](http://ed25519.cr.yp.to/) تولید می‌کند که می‌توان از آن برای ایجاد یک کش باینری امضا شده استفاده کرد. این دستور سه پارامتر اجباری دریافت می‌کند:

1. یک نام کلید، مانند `cache.example.org-1`، که هنگام اعتبارسنجی امضاها توسط کلاینت برای جستجوی کلیدها استفاده می‌شود. این نام می‌تواند هر چیزی باشد، اما پیشنهاد می‌شود از نام هاستِ کش خود (مثلاً `cache.example.org`) به همراه پسوندی که شماره کلید را نشان می‌دهد (و باید هر بار که نیاز به ابطال کلید دارید افزایش یابد) استفاده کنید.

2. نام فایلی که کلید خصوصی در آن ذخیره می‌شود.

3. نام فایلی که کلید عمومی در آن ذخیره می‌شود.
