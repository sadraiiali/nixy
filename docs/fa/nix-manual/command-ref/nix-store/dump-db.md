# نام

`nix-store --dump-db` - برون‌بری پایگاه‌داده Nix

# خلاصه دستور

`nix-store` `--dump-db` [*paths…*]

# توضیحات

عملیات `--dump-db` یک خروجی (dump) از پایگاه‌داده Nix را روی خروجی استاندارد می‌نویسد. این خروجی را می‌توان با استفاده از `--load-db` درون یک انبار Nix خالی بارگذاری کرد. این کار برای تهیه پشتیبان و هنگام مهاجرت به شمای پایگاه‌داده متفاوت مفید است.

به طور پیش‌فرض، `--dump-db` کل پایگاه‌داده Nix را برون‌بری می‌کند. هنگامی که یک یا چند مسیر انبار پاس داده شوند، فقط زیرمجموعه‌ای از پایگاه‌داده Nix که مربوط به آن مسیرهای انبار است برون‌بری می‌شود. همانند `--export`، کاربر مسئول پاس دادن تمام مسیرهای انبار برای یک closure است. برای مشاهده یک مثال، به `--export` مراجعه کنید.
