# نام

`nix-store --load-db` - وارد کردن پایگاه داده Nix

# خلاصه

`nix-store` `--load-db`

# توضیحات

عملیات `--load-db` یک دامپ از پایگاه داده Nix را که توسط `--dump-db` ایجاد شده‌است، از ورودی استاندارد می‌خواند و آن را در پایگاه داده Nix بارگذاری می‌کند.
