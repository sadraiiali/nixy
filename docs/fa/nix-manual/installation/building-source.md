# ساخت Nix از روی کد منبع

نکست با [Meson](https://mesonbuild.com/) ساخته می‌شود.
این ابزار به چندین بسته Meson تقسیم شده‌است که در صورت تمایل می‌توان آن‌ها را با استفاده از ویژگی [subprojects](https://mesonbuild.com/Subprojects.html) در Meson، در یک پروژه واحد با یکدیگر ترکیب کرد.

هیچ مرحله اضافی اجباری در فرآیند ساخت وجود ندارد:
دستورالعمل‌های عمومی نصب Meson مانند [این مورد](https://mesonbuild.com/Quick-guide.html#using-meson-as-a-distro-packager) باید بهران انجام شوند.

```bash
git clone https://github.com/NixOS/nix.git
cd nix
meson setup build
cd build
ninja
(sudo) ninja install
```

مسیر نصب را می‌توان با ارسال `-Dprefix=prefix` به دستور `meson setup build` مشخص کرد. پوشه نصب پیش‌فرض `/usr/local` است. می‌توانید این مقدار را به هر مکانی که دوست دارید تغییر دهید. شما باید دسترسی نوشتن به مسیر *prefix* داشته باشید.

Nix *انبار* خود (محیطی که بسته‌ها در آن ذخیره می‌شوند) را به‌طور پیش‌فرض در `/nix/store` نگه می‌دارد. این مقدار را می‌توان با استفاده از `-Dlibstore:store-dir=path` تغییر داد.

> **هشدار**
>
> بهتر است انبار Nix را از حالت پیش‌فرض خود تغییر *ندهید*، زیرا انجام این کار استفاده از باینری‌های پیش‌ساخته‌ی کانال‌های استاندارد Nixpkgs را غیرممکن می‌سازد؛ یعنی تمام بسته‌ها باید از روی کد منبع ساخته شوند.

Nix وضعیت (مانند پایگاه داده و فایل‌های ثبت وقایع) خود را به‌طور پیش‌فرض در `/nix/var` نگه می‌دارد. این مقدار را می‌توان با استفاده از `-Dlocalstatedir=path` تغییر داد.
