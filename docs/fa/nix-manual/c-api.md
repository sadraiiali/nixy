# رابط برنامه‌نویسی C

Nix یک رابط برنامه‌نویسی C با این هدف ارائه می‌دهد که [_به_](https://github.com/NixOS/nix/milestone/52) یک رابط برنامه‌نویسی پایدار تبدیل شود؛ هدفی که در حال حاضر محقق نشده‌است.
این رابط در حال توسعه است.
