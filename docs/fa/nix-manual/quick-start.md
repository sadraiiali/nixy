# شروع سریع

این فصل برای افرادی است که حوصله ندارند و خواندن مستندات را دوست ندارند.
برای کسب اطلاعات عمیق‌تر، لطفاً به فصل‌های بعدی مراجعه کنید.

1. نصب Nix:
```console
   $ curl -L https://nixos.org/nix/install | sh
   ```

اسکریپت نصب از `sudo` استفاده خواهد کرد، بنابراین مطمئن شوید که دسترسی‌های لازم را دارید.

   برای سایر روش‌های نصب، دستورالعمل‌های دقیق [installation instructions](installation/index.md) را ببینید.

1. اجرای نرم‌افزار بدون نصب دائم آن:
```console
   $ nix-shell --packages cowsay lolcat
   ```

این کار بسته‌های مشخص‌شده را به همراه تمام وابستگی‌هایشان بارگیری کرده و شما را وارد یک شل Bash می‌کند که در آن دستورات ارائه‌شده توسط آن بسته‌ها در دسترس هستند.
این کار هیچ تأثیری روی محیط عادی شما نخواهد گذاشت:
```console
   [nix-shell:~]$ cowsay Hello, Nix! | lolcat
   ```

خروج از شل باعث می‌شود که برنامه‌ها دوباره ناپدید شوند:
```console
   [nix-shell:~]$ exit
   $ lolcat
   lolcat: command not found
   ```

1. برای جستجوی بسته‌های بیشتر جهت امتحان کردن، به [search.nixos.org](https://search.nixos.org/) مراجعه کنید.

1. آزاد کردن فضای ذخیره‌سازی:
```console
   $ nix-collect-garbage
   ```
