# مجموعه ویژگی‌ها: rec

> درس **۱۲** از ۳۵ · مسیر `attrset/rec`

`مجموعه‌ها` یا `مجموعه‌های ویژگی` در واقع **هستهٔ اصلی زبان Nix** هستند، زیرا در نهایت این زبان
کاملاً پیرامون ساخت درایویشن‌ها می‌چرخد، که در واقع
همان `مجموعه‌های ویژگی` ارائه‌شده به اسکریپت‌های ساخت هستند.

مجموعه‌ها صرفاً فهرستی از جفت‌های نام-مقدار (که صفت نامیده می‌شوند)
هستند که در آکولاد محصور شده‌اند، به طوری که هر مقدار یک
عبارت دلخواه است که با یک نقطه ویرگول خاتمه می‌یابد. برای مثال:

    { x = 123;
      text = "Hello";
      y = f { bla = 456; };
    }

این کد یک مجموعه با صفاتی به نام‌های x، text و y تعریف می‌کند. ترتیب صفت‌ها اهمیتی ندارد. نام هر صفت تنها یک بار می‌تواند ظاهر شود.

اکنون:

* دریابید کلیدواژه `rec` چه کاری انجام می‌دهد و چه تفاوتی با یک `مجموعه ویژگی` بدون `rec` دارد.
* `rec` را پیش از `مجموعه ویژگی` حذف کنید و رفتار متفاوت مفسر nix را مشاهده کنید.

**راهنمایی:** پاسخ را در بخش راه‌حل پیدا خواهید کرد.

**نکته:** فعلاً همین اندازه کافی است، اما می‌توانید به مطالعه ادامه دهید [مستندات نیکس](https://nixos.org/manual/nix/stable/language/constructs.html#recursive-sets).

## کد اولیه

```nix
rec {
  x = "a";
  y = x;
}
```

## راه‌حل

```nix
rec {
  x = "a";
  y = x;
}
#Recursive sets are just normal sets, but the attributes can refer to each other.
#Be aware of infinite recursions. They are not possible!
#rec {
#  x = y;
#  y = x;
#} Does not Work.
```
