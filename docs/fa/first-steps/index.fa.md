# گام‌های نخستین

این مجموعه آموزشی نقطهٔ شروع مناسبی برای یادگیری Nix است.

در این درس‌ها، شما با استفاده از دستورات پایه‌ای Nix، تقریباً هر نرم‌افزاری را دریافت می‌کنید، محیط‌های توسعه را به‌صورت آنی (ad-hoc) می‌سازید و یادمی‌گیرید چگونه اسکریپت‌های تکرارپذیر بنویسید.
همچنین خواندن زبان Nix را خواهید آموخت و بعداً از آن برای ساخت محیط‌های توسعهٔ قابل‌حمل و بازتولیدپذیر استفاده خواهید کرد.
