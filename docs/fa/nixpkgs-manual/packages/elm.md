# Elm {#sec-elm}

برای راه‌اندازی یک محیط توسعه، اجرا کنید:

```ShellSession
nix-shell -p elmPackages.elm elmPackages.elm-format
```

برای به‌روزرسانی کامپایلر Elm، فایل `nixpkgs/pkgs/development/compilers/elm/README.md` را ببینید.

برای بسته‌بندی برنامه‌های Elm، [دربارهٔ elm2nix بخوانید](https://github.com/hercules-ci/elm2nix#elm2nix).
