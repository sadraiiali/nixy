# باز کردن ایشوها {#sec-opening-issues}

* مطمئن شوید که یک [حساب کاربری GitHub](https://github.com/signup/free) دارید
* مطمئن شوید که هیچ ایشوی بازی در مورد این موضوع وجود ندارد
* با انتخاب نوع موضوع و تکمیل قالب، [یک ایشوی جدید ثبت کنید](https://github.com/NixOS/nixpkgs/issues/new/choose)
