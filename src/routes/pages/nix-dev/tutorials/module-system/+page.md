# <a id="module-system-tutorial"></a> سیستم ماژول

بخش زیادی از قدرت Nixpkgs و NixOS از سیستم ماژول سرچشمه می‌گیرد.

سیستم ماژول یک کتابخانه زبان Nix است که به شما امکان می‌دهد تا:

- یک مجموعه ویژگی را با استفاده از عبارت‌های مختلف و مجزای Nix اعلام کنید.
- محدودیت‌های نوع را روی مقادیر موجود در آن مجموعه ویژگی اعمال کنید.
- مقادیری را برای همان صفت در عبارت‌های مختلف Nix تعریف کنید و این مقادیر را به طور خودکار بر اساس نوعشان ادغام کنید.

این عبارت‌های Nix ماژول نامیده می‌شوند و باید ساختار خاصی داشته باشند.

در این مجموعه آموزشی خواهید آموخت:

- ماژول چیست و چگونه می‌توان یکی ساخت.
- گزینه‌ها چیستند و چگونه باید آن‌ها را اعلام کرد.
- چگونه وابستگی‌های بین ماژول‌ها را بیان کنیم.
