# <a id="first-steps"></a> گام‌های نخستین

این مجموعه آموزشی نقطه‌ی شروع مناسبی برای یادگیری Nix است.

در این درس‌ها، شما با استفاده از دستورات پایه‌ای Nix، تقریباً هر نرم‌افزاری را دریافت می‌کنید، محیط‌های توسعه را به‌صورت آنی (ad-hoc) می‌سازید و یاد می‌گیرید چگونه اسکریپت‌های تکرارپذیر بنویسید.
همچنین خواندن زبان Nix را خواهید آموخت و بعداً از آن برای ساخت محیط‌های توسعه‌ی قابل‌حمل و بازتولیدپذیر استفاده خواهید کرد.
