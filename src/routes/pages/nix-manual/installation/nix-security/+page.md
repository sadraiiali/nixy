# 3.5. امنیت

نیکس (Nix) دو مدل امنیتی پایه دارد. نخست، می‌تواند در «حالت تک‌کاربره» استفاده شود که مشابه کاری است که اکثر ابزارهای مدیریت بسته دیگر انجام می‌دهند: یک کاربر واحد (معمولاً root) وجود دارد که تمام عملیات مدیریت بسته را انجام می‌دهد. سپس سایر کاربران می‌توانند از بسته‌های نصب‌شده استفاده کنند، اما خودشان نمی‌توانند عملیات مدیریت بسته را انجام دهند.

به‌عنوان روشی جایگزین، می‌توانید Nix را در «حالت چندکاربره» پیکربندی کنید. در این مدل، همه کاربران می‌توانند عملیات مدیریت بسته را انجام دهند؛ برای نمونه، هر کاربر می‌تواند بدون نیاز به دسترسی‌های root، نرم‌افزار نصب کند. نیکس تضمین می‌کند که این کار امن است. برای مثال، برای یک کاربر امکان‌پذیر نیست که بسته‌ای را که توسط کاربر دیگری استفاده می‌شود، با یک اسب تروجان بازنویسی کند.
