# 3.3.2. تهیه توزیع کد منبع

جدیدترین کدهای منبع Nix را می‌توان از [مخزن Git](https://github.com/NixOS/nix) آن دریافت کرد. برای مثال، دستور زیر آخرین نسخه را در پوشه‌ای به نام `nix` بررسی و دریافت (checkout) می‌کند:

```shell
$ git clone https://github.com/NixOS/nix
```

به همین ترتیب، نسخه‌های خاص را می‌توان از [تگ‌ها (Tags)](https://github.com/NixOS/nix/tags) مخزن دریافت کرد.
