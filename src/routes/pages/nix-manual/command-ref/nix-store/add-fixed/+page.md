# 8.3.3.1. nix-store --add-fixed

## نام

`nix-store --add-fixed` - افزودن مسیرها به انبار با استفاده از الگوریتم هش مشخص‌شده

## خلاصه

`nix-store` `--add-fixed` [`--recursive`] *algorithm* *paths…*

## توضیحات

عملکرد `--add-fixed` مسیرهای مشخص‌شده را به انبار Nix اضافه می‌کند.
بر خلاف `--add`، مسیرها با استفاده از الگوریتم هش مشخص‌شده ثبت می‌شوند که نتیجه‌ی آن، مسیر خروجی مشابهی با یک derivation خروجی-ثابت خواهد بود. این کار را می‌توان برای کدهای منبعی استفاده کرد که از یک URL عمومی در دسترس نیستند یا از زمان نگارش عبارت بارگیری، از کار افتاده‌اند.

این عملکرد دارای گزینه‌های زیر است:

- `--recursive`

  به‌جای حالت هش تخت، از حالت هش بازگشتی استفاده کنید؛ این گزینه هنگام افزودن پوشه‌ها به انبار استفاده می‌شود.

  *paths*هایی که به پیوندهای نمادین (symlinks) اشاره دارند، ارجاع‌زدایی (dereference) نمی‌شوند، بلکه به عنوان پیوندهای نمادین با همان مقصد به انبار اضافه می‌شوند.

## مثال

```shell
$ nix-store --add-fixed sha256 ./hello-2.10.tar.gz
/nix/store/8alrpdaasjd1x6g1fczchmzbpqm936a3-hello-2.10.tar.gz
```
