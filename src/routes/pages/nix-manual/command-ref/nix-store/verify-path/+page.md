# 8.3.3.19. nix-store --verify-path

## نام

`nix-store --verify-path` - بررسی محتویات مسیر در برابر پایگاه‌داده‌ی نیکس

## خلاصه‌ی دستور

```text
nix-store --verify-path paths…
```

## توضیحات

عملیات `--verify-path` محتویات مسیرهای انبار مشخص‌شده را با هش‌های رمزنگاری‌شده‌ی آن‌ها که در پایگاه‌داده‌ی Nix ذخیره شده‌اند، مقایسه می‌کند. برای هر مسیر تغییریافته، یک پیام هشدار چاپ می‌کند. اگر هیچ مسیری تغییر نکرده باشد، وضعیت خروج ۰ و در غیر این صورت ۱ خواهد بود.

## مثال

برای بررسی یکپارچگی دستور `svn` و تمام وابستگی‌های آن:

```shell
$ nix-store --verify-path $(nix-store --query --requisites $(which svn))
```
