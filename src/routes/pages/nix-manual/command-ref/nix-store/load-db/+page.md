# 8.3.3.10. nix-store --load-db

## نام

`nix-store --load-db` - وارد کردن پایگاه داده Nix

## خلاصه

```text
nix-store --load-db
```

## توضیحات
عملیات `--load-db` یک دامپ از پایگاه داده Nix را که توسط `--dump-db` ایجاد شده است، از ورودی استاندارد می‌خواند و آن را در پایگاه داده Nix بارگذاری می‌کند.
