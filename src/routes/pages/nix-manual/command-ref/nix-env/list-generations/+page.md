# 8.3.4.3. nix-env --list-generations

## نام

`nix-env --list-generations` - فهرست کردن نسل‌های پروفایل

## خلاصه

```text
nix-env --list-generations
```

## توضیحات
این عملیات فهرستی از تمام نسل‌های در حال حاضر موجود برای پروفایل فعال را چاپ می‌کند. با استفاده از عملیات `--switch-generation` می‌توان به این نسل‌ها سوئیچ کرد. همچنین تاریخ ایجاد نسل را چاپ کرده و نسل فعلی را مشخص می‌کند.

## مثال‌ها
```shell
$ nix-env --list-generations
  95   2004-02-06 11:48:24
  96   2004-02-06 11:49:01
  97   2004-02-06 16:22:45
  98   2004-02-06 16:24:33   (current)
```
