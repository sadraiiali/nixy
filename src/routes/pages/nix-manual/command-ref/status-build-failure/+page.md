# کدهای خروج ویژه برای خرابی ساخت

کدهای وضعیت 1xx زمانی استفاده می‌شوند که ساخت‌های درخواست‌شده با شکست مواجه شوند.
کدهای زیر در حال استفاده هستند:

- `100` خرابی عمومی ساخت

  فرآیند سازنده با یک کد خروج غیرصفر بازگشت.

- `101` پایان زمان ساخت (Timeout)

  ساخت به این دلیل متوقف شد که ظرف مدت‌زمان تعیین‌شده‌ی `timeout` کامل نشد.

- `102` عدم تطابق هش

  خروجی ساخت رد شد زیرا با [`outputHash` attribute of the derivation](/pages/nix-manual/language/advanced-attributes) مطابقت ندارد.

- `104` غیر قطعی

  ساخت در حالت بررسی (check mode) موفق بود، اما خروجی حاصل از نظر باینری بازتولیدپذیر نیست.

با پرچم `--keep-going` این امکان وجود دارد که چندین خرابی رخ دهد.
در این صورت، کدهای وضعیت 1xx با استفاده از [عملگر بیتی OR](https://en.wikipedia.org/wiki/Bitwise_operation#OR) با یکدیگر ترکیب (OR) می‌شوند.

```
0b1100100
     ^^^^
     |||`- timeout
     ||`-- output hash mismatch
     |`--- build failure
     `---- not deterministic
```
