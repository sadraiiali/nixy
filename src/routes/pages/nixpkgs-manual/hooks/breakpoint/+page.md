# <a id="breakpointhook"></a> breakpointHook

این قلاب باعث می‌شود هنگام بروز خطا، فرآیند ساخت به جای متوقف شدن کامل، مکث کند. این ویژگی از پاک‌سازی فوری محیط ساخت توسط Nix جلوگیری کرده و به کاربر اجازه می‌دهد به محیط ساخت متصل شود. هنگام بروز خطای ساخت، دستورالعمل‌هایی چاپ می‌شود که می‌توان از آن‌ها برای ورود به محیط جهت دیباگ (اشکال‌زدایی) استفاده کرد. `breakpointHook` تنها در Linux در دسترس است. برای استفاده از آن، `breakpointHook` را به `nativeBuildInputs` در بسته مورد بررسی اضافه کنید.

```nix
{ nativeBuildInputs = [ breakpointHook ]; }
```

هنگامی که شکست ساخت رخ می‌دهد، دستورالعملی چاپ خواهد شد که نحوهٔ اتصال به محیط ایزوله شده (Sandboxed) ساخت را نشان می‌دهد.

> <span class="admonition-kind" data-kind="note"></span>
>
> **نکته**
>
> احتیاط در مورد ساخت‌های راه دور
>
> برای ساخت‌های راه دور، دستورالعمل‌های چاپ‌شده باید روی ماشین راه دور اجرا شوند، چرا که محیط ایزوله شده (Sandboxed) ساخت تنها روی ماشینی که ساخت‌ها را اجرا می‌کند قابل دسترسی است. ساخت‌های راه دور را می‌توان با تنظیم `--option builders ''` برای `nix-build` یا `--builders ''` برای `nix build` غیرفعال کرد. :::
