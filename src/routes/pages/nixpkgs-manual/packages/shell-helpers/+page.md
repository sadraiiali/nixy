# <a id="sec-shell-helpers"></a> ابزارهای کمکی شل تعاملی

برخی بسته‌ها یکپارچه‌سازی با شل را ارائه می‌دهند تا کاربردی‌تر باشند. اما برخلاف سیستم‌های دیگر، Nix دارای مکان پوشه استاندارد `share` نیست. به همین دلیل مجموعه‌ای از اسکریپت‌های `PACKAGE-share` عرضه می‌شوند که مکان پوشه اشتراکی مربوطه را چاپ می‌کنند. فهرست فعلی چنین بسته‌هایی به شرح زیر است:

- `fzf` : `fzf-share`

به عنوان مثال، سپس می‌توان از `fzf` در `.bashrc` به این صورت استفاده کرد:

```bash
source "$(fzf-share)/completion.bash"
source "$(fzf-share)/key-bindings.bash"
```
