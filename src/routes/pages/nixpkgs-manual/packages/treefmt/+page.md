# <a id="treefmt"></a> treefmt

- `treefmt-functions`

صفات زیر را می‌توان به [`withConfig`](#pkgs.treefmt.withConfig) یا [`evalConfig`](#pkgs.treefmt.evalConfig) پاس داد:

- `id-prefix: opt-treefmt-`
- `list-id: configuration-variable-list`
- `treefmt-options`
